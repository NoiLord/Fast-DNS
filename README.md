# Fast-DNS

Статический адаптивный сайт. Запуск: `npm start`, затем http://127.0.0.1:4173. Проверка JavaScript: `npm run check`. Готовая папка для размещения: `dist/`.

Содержимое основано на предоставленной конфигурации, а не на живой проверке сервера. Нет автоматической диагностики DNS или обещаний доступности. Работают фильтры сервисов, переключение инструкций, копирование IP и FAQ.

Иллюстрация `dist/assets/portal.png` создана встроенным image_gen по выбранному пользователем эскизу: прозрачный фиолетовый портал, чёрный геймпад, лаймовая орбита, обсидиановые камни на тёмном фоне, без надписей и интерфейса. Полный исходный запрос сохранён в истории чата. Шрифт Golos Text загружается с Google Fonts; при недоступности используется Arial.
